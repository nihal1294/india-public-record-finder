# Two-minute demonstration script

Use the built-in fictional examples and keep the narration aligned with the
visible state. All four citizen actions finish in the first minute; the second
minute explains how the product is built and why its boundaries matter. The
complete sequence is 02:00.

```text
00:00–00:08  Open the site; read “Find a record. Verify the source.” and the synthetic-only boundary.
00:08–00:20  Run Exact Kannada; show the candidate, match reasons, and source crop.
00:20–00:31  Run Romanized typo; show recovery without changing the demo data.
00:31–00:46  Run Needs refinement; apply the declared detail and verify the source.
00:46–01:00  Run No confident match; show the safe non-assertive response and Reset.
01:00–01:18  Explain the deterministic synthetic source snapshot, validated records, evidence crops, and no OCR in the search path.
01:18–01:42  Explain Kannada/Latin aliases, self-hosted hybrid retrieval, deterministic scoring, and no third-party embedding provider.
01:42–02:00  Explain why source verification matters, why OCR remains outside the citizen search path until its accuracy bar is met, and how state/system adapters extend the pattern.
```

Keep the source crop and the “Possible match — not an official
determination.” language visible when discussing a candidate. Do not enter
real personal information.
